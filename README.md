# FitLog — Workout Library

A workout library web application where users can explore workouts, create daily plans, save exercises, and track completed workouts.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI

## 5 Key Features
1. Browse workouts with detailed information.
2. View individual workout details and instructions.
3. Add workouts to Today's Plan.
4. Save workouts for later.
5. Mark workouts as completed and sort by duration, calories, or rating.
